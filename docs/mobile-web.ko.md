# 모바일 웹 (베타)

[English](mobile-web.md) · [README로 돌아가기](../README.ko.md)

휴대폰이나 태블릿에서 OMPdesk를 써요. 실행 중인 작업에 추가 지시를 보내고, 질문에 답하고, 결과를 읽을 수 있어요. **베타이고 기본값은 꺼짐**이에요. 모든 휴대폰에서 실제 기기 점검을 마치지는 않았어요.

페이지는 내 컴퓨터의 OMPdesk가 제공하고, 내 [Tailscale](https://tailscale.com) 네트워크에만 공개돼요. 별도 서버를 거치지 않고, 내 tailnet의 기기만 열 수 있어요. **페어링 코드는 없어요.** 내 Tailscale 계정으로 로그인한 기기가 링크를 열면 바로 연결돼요.

## 설정하기

1. 컴퓨터에서 **설정 › 기기 및 연결 › 모바일 웹**을 열고 **폰과 태블릿에서 OMPdesk 사용**을 켜세요. Tailscale 설치, 로그인, (tailnet에 필요하면) HTTPS 인증서 켜기처럼 빠진 단계를 OMPdesk가 차례로 안내해요.
2. 휴대폰에 Tailscale을 설치하고 같은 계정으로 로그인하세요.
3. **링크 복사**를 누르거나 옆의 QR 코드를 읽어서 휴대폰에서 링크를 여세요. 처음 열면 바로 연결돼요. 코드를 입력하거나 따로 승인할 필요가 없어요.
4. 선택: iPhone과 iPad는 공유 › 홈 화면에 추가를 누르면 앱처럼 쓰고 알림도 받을 수 있어요.

새 기기가 연결되면 컴퓨터에 조용한 알림이 하나 떠요(예: "새 기기가 연결됐어요: SeuPut S25U"). 알림에는 **차단** 버튼이 있어요. 먼저 허락하고 싶다면 **새 기기는 컴퓨터에서 승인 후 연결**을 켜세요(기본값 꺼짐). 그러면 새 기기가 컴퓨터의 대화상자에서 허락을 받아야 연결돼요.

*다른* Tailscale 계정으로 로그인한 기기가 링크를 열면, 그렇다고 알려 주고 열 수 있는 계정을 알려 주는 페이지가 보여요.

## 알림

휴대폰의 **설정 › 모바일 웹**에서 **이 기기의 알림**은 기기마다 직접 켜야 해요. 켜면 페이지를 닫아 둔 동안에도 에이전트가 끝나거나 실패하거나 질문할 때 알려 줘요. **내용 숨기기**를 켜면 세션 이름이나 글 없이 무슨 일이 있었는지만 보여요.

## 누가 무엇을 할 수 있는지 정하기

- **연결된 기기**에 폰과 태블릿이 모두 Tailscale 기기 이름으로 보여요. 이름을 바꾸고, 권한 등급(**전체 권한**, **컴퓨터 제어 제외**, **채팅과 보기만**, **사용자 지정**)을 바꾸고, **차단**할 수 있어요.
- **차단**하면 다음에 다시 열 때까지만이 아니라 계속 막혀요. 차단은 그 기기의 Tailscale 노드에 걸리므로 다른 기기는 그대로 쓸 수 있어요. 차단된 기기에는 "이 기기는 차단됐어요" 페이지가 보이고 다시 연결할 수 없어요. 어느 기기인지 Tailscale이 알려 주지 않으면 그 계정으로 로그인한 모든 기기를 차단하고, 확인 창에서 그렇다고 알려 줘요. 차단한 기기는 **차단한 기기** 목록에 있고, **차단 해제**를 누르면 다음에 열 때 다시 연결돼요.
- **허용된 Tailscale 사용자**는 코드 없이 기기를 연결할 수 있는 계정이에요. 이 컴퓨터의 계정은 기본으로 허용돼요.
- 스위치를 끄면 OMPdesk가 만든 Tailscale 항목만 지워요.
- Tailscale Funnel이 포트를 공개 인터넷에 열어 두면 모바일 웹은 시작하지 않아요. 그 포트의 Funnel을 끄세요.

## 보안은 어떻게 되어 있나요

신원은 Tailscale 계정이에요. `tailscale serve`가 요청이 어느 계정에서 왔는지 알려 주고(`Tailscale-User-Login` 헤더), OMPdesk는 아래를 모두 만족할 때만 그 말을 믿어요.

- 요청이 `tailscale serve`를 거쳐 왔어요. OMPdesk는 설치마다 다른 비밀 경로(`serve --bg --https=<포트> http://127.0.0.1:<로컬 포트>/<비밀>`)로 게시하고, 페이지는 그 경로를 보지 못해요. 경로가 없는 요청은 404이고 그 요청의 헤더는 읽지도 않아요. 컴퓨터 안의 다른 프로그램이 같은 헤더를 OMPdesk의 로컬 포트에 곧바로 써도 아무것도 얻지 못해요.
- 게시한 주소(Host, Origin, fetch 사이트 검사)로 컴퓨터 자신의 루프백에서 왔고, Tailscale Funnel(공개 인터넷) 요청이 아니에요. Funnel 요청은 항상 거부해요.
- 허용된 계정이에요.

그다음 기기는 자기 쿠키와 키를 받고, 이후 방문에는 그것을 써요. 한계: 비밀은 `web-serve-secret.json`(권한 0600)과 serve 설정에 있어서 내 계정으로 실행되는 프로그램은 읽을 수 있어요. 하지만 그런 프로그램은 OMPdesk의 쿠키 저장소와 내 파일도 이미 읽을 수 있어요. 내 Tailscale 기기를 공유한 사람이나 허용한 계정의 사용자는 기기를 연결할 수 있어요. 믿을 수 있는 계정만 허용하고, 하나씩 보고 싶다면 **새 기기는 컴퓨터에서 승인 후 연결**을 켜세요.

## 한계

휴대폰은 추가 지시와 읽기를 위한 화면이에요. 미리보기와 터미널은 휴대폰에서도 쓸 수 있고, 컴퓨터에서 파일이나 링크를 여는 것은 **이 컴퓨터 제어** 권한이 있어야 해요.
