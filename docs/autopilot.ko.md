# 오토파일럿

[English](autopilot.md) · [README로 돌아가기](../README.ko.md)

오토파일럿은 끝내라고 할 때까지 프로젝트를 혼자 계속 개발해요. 사이클마다 코드를 살펴보고, 가장 가치 있는 일과 함께 끝낼 수 있는 서로 독립된 일들을 골라 동시에 구현하고, 프로젝트의 검사를 돌린 뒤 하나씩 커밋해요. 새 git 워크트리에서 일하므로 내 폴더와 지금 브랜치는 건드리지 않아요.

## 시작하기

1. git 저장소에서 세션을 열어요.
2. 작성기의 실행 칩을 열고 모드에서 **오토파일럿**을 고른 뒤 **오토파일럿 시작**을 눌러요.

실행은 새 탭에서, 내 폴더에 체크아웃된 브랜치를 바탕으로 만든 새 브랜치 `autopilot/<날짜>`에서 시작해요. 탭 이름은 지금 사이클이 고른 항목을 따라 사이클마다 바뀌어요(직접 바꾼 이름은 그대로 둬요). 사이드바 줄, 타이틀바, 작업 보드의 로켓 아이콘이 이 탭이 실행이라는 표시예요. 따로 정할 건 없어요. 같은 곳의 **고급**에는 이런 것이 있어요.

- **내보내기**: 초록 사이클이 어디로 가는지(아래 참고)
- **브랜치**: 실행이 시작하는 폴더의 브랜치
- **초점** 영역(디자인, 성능, 기능, 리팩터링, 테스트, 버그, 문서). 하나도 고르지 않으면 전부예요.

## 작업은 어디로 가나요

다른 단계를 고르지 않으면 내보내기는 **자동**이에요.

- 리모트가 있으면 커밋을 만든 **초록** 사이클마다 기본 브랜치에 착지해요. 그 사이 다른 사람이 기본 브랜치를 움직였다면 OMPdesk가 따로 체크아웃해서 병합하고, 병합한 결과에서 그 사이클의 검사를 돌린 뒤에 푸시해요. 충돌이 나거나 검사가 실패하면 아무것도 착지하지 않고, 에이전트에게 먼저 병합하라고 알려요. 보호된 브랜치라면 대신 풀 리퀘스트 하나를 만들고, 이후 사이클이 그 PR을 갱신해요.
- 리모트가 없으면 커밋은 내 컴퓨터에만 남아요.
- 빨간 사이클이나 커밋이 없는 사이클은 착지하지 않아요.
- 프로젝트에 이미 배포 절차가 있을 때만 배포해요. 규칙 파일(`AGENTS.md`, `CLAUDE.md`, `CONTRIBUTING.md`)이나 `AUTOPILOT.md`의 배포 섹션에 있어야 해요. 언제 배포할지는 시간이 아니라 마지막 배포 뒤에 착지한 내용으로 정해요. 사용자에게 보이는 변경(기능, 수정, 속도 개선)이 3건 모였을 때, 배포된 앱을 망가뜨린 문제를 고쳤을 때, 사용자에게 보이는 변경이 하루를 기다렸을 때예요. 문서, 테스트, 리팩터링만으로는 배포하지 않아요.

고급의 **커밋**, **푸시**, **배포**를 고르면 커밋을 내 컴퓨터에만 두거나, 실행의 브랜치만 푸시하거나, 푸시하고 배포해요.

## 방향 잡기

- **작업 현황.** 실행 탭에는 그 실행의 작업 현황이 보여요. 실행 상태, 진행 중인 사이클과 그 단계, 최근 사이클(누르면 커밋, 시간, 바뀐 내용, **되돌리기**), 사이클이 남긴 후속 작업, 집중 영역(눌러서 바꿔요)이에요. 좁은 창이나 분할 창, 휴대폰에서는 머리줄 아래 띠를 눌러 열어요.
- **남은 후속 작업.** 앞선 사이클이 찾았지만 하지 않은 일이에요. 그 일을 한 사이클이나, 더는 해당하지 않는다고 본 사이클이 닫아요. ✕를 누르면 에이전트 목록에서 빠져요. 나중 사이클이 같은 일을 다시 찾으면 다시 올라와요. 다음 사이클이 먼저 할 일은 실행 탭의 입력창에 적어요.
- **직접 말하기.** 다른 세션처럼 실행 탭의 작성기에 입력해요. 진행 중인 사이클은 그 메시지를 방향 지시로 받아요. 푸시나 배포를 해 달라는 요청은 런타임에 전달돼요.
- **`AUTOPILOT.md`.** 시작할 때 OMPdesk가 프로젝트 안내서(목표, 우선순위, 건드리지 말 경로, 완료의 기준, 배포 방법)를 써서 실행의 첫 커밋으로 남겨요. 그래서 작업과 함께 기본 브랜치에 들어가요. 다른 파일처럼 고치면 되고, 사이클마다 다시 읽어요. 저장소의 규칙 파일과 다르면 규칙 파일이 우선해요.

## 멈추기

- **일시정지**는 지금 턴을 마치고 새 사이클을 시작하지 않아요. **재개**하면 이어서 해요.
- **종료**는 진행 중인 사이클을 마친 뒤 실행을 끝내요.
- **즉시 중단**은 턴을 바로 멈추고 실행을 일시정지해요.

빨간 사이클, 실패한 검사, 거절된 푸시로는 스스로 멈추지 않아요. 다음 사이클이 고쳐요. 일시정지하는 경우는 사용자가 멈췄을 때, 예상하지 못한 git 변경이 있을 때, 저장소 폴더가 사라졌을 때, 그리고 **다시 열 때 중단된 작업 이어서 하기**가 꺼진 상태에서 OMPdesk를 닫았을 때뿐이에요. 사용 한도에 걸리면 기다렸다가 초기화 시각에 스스로 이어서 해요. 충돌, 업데이트, 일반 종료 뒤에는 다음 실행 때 이어서 해요.

## 하지 않는 일

- 강제 푸시, 기록 다시 쓰기, reset, 브랜치 삭제는 하지 않아요. 에이전트는 직접 푸시하지 않고, 착지·푸시·배포는 내보내기 단계가 허락하는 대로 OMPdesk만 해요.
- 워크트리 밖은 고치지 않고, 비밀값을 커밋하지 않으며, 계정이나 설정을 바꾸지 않아요.

## 알림

일시정지하거나 멈출 때, 끝날 때, 배포 결과가 나왔을 때 알려요. 사이클마다 알리지는 않아요. 끝나거나 일시정지할 때마다 요약 한 줄(사이클 수, 초록 수, 커밋 수, 착지한 것)을 OMPdesk 로그에도 남겨요.

## 다른 컴퓨터에서

연결한 컴퓨터의 폴더를 연 세션에서 시작하면([원격 기기](remote-devices.ko.md) 참고) 오토파일럿은 그 컴퓨터의 창에 탭으로 실행돼요. 이 기기에서 탭을 닫거나 연결이 끊겨도 계속 돌아가요.
