# Competing attempts in worktrees: compare, then merge

1. Open each attempt with `worktree: true` (branch `omp/agent/<slug>`, its own checkout beside the repo; this computer's sessions only). Its brief says: commit on your branch when done, run the tests, put the result in your final answer.
2. Wait for all: `ompdesk_session_result` with `sessions` and `wait`.
3. `ompdesk_compare` (`sessions`, default your worktree children): branch, commits ahead of the parent, changed files with +/−, uncommitted work, the checks each transcript ran and the final answer. With `criteria` a judge model ranks them and names a winner: skill://ompdesk/references/across.md. It runs no tests itself. Read a thin one with `ompdesk_session_read`.
4. Read each child's work inside its own worktree. A path in its answer that points into the main checkout is not where its work is; never edit there on its behalf.
5. Pick the winner, say why, and `ompdesk_merge` (`session`): a merge commit into the parent checkout's current branch, local, never pushed. No card by default; the user confirms first only if they turned off both full control and "Let agents manage other sessions". It refuses a detached parent, uncommitted work in the child or the parent (ask the child to commit) and a branch with nothing to merge, and aborts a conflicting merge naming the files; then ask the child to rebase or resolve, or tell the user.
6. You review and land your own children; nobody clicks Approve or Discard on a board (the work board shows them only as status rows). A branch counts as landed when its tip is in the parent checkout's HEAD or in the upstream it tracks, so it needs no merge. For each child: merge it (`ompdesk_merge`) or discard it (`ompdesk_session_stop` with `close`, or `delete` to drop the saved session too; it leaves the worktree and branch, which you may mention to the user). A child that needs the person (a question, a blocker, a plan waiting for approval) shows as a waiting row and a notification: answer what you can, tell the user the rest. A finished child you collected, whose work landed and that nobody is using, closes by itself and stays saved.
