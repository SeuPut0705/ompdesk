# ECC language and framework skills (OMPdesk built-in)

This folder is a copy of [ECC](https://github.com/affaan-m/ECC)'s omp/pi profile `pi/core` by Affaan Mustafa (MIT, see `UPSTREAM-LICENSE`), pinned in `ecc-config.json`. OMPdesk loads it as an omp extension root while Settings › Agent behavior › ECC language and framework skills is on. Upstream's own exclusions are in `UPSTREAM-CURATION.md`; OMPdesk's are in the pin's `curation`.

Changes from upstream: every skill is hidden from the model's skill list and named by the generated index skill `ecc`; skills that restate a pstack workflow are left out and references to them point at pstack's counterpart; the `plan` command is `ecc-plan` (`/plan` is stock omp's); `AskUserQuestion` and the Task tool are omp's `ask` and `task`; ECC's working files go under `.ecc/` instead of `.claude/`.

Generated by `bun run sync:ecc`; `ecc-config.json` and this file are written by hand. Do not edit generated files: `ecc-manifest.json` lists their checksums. There is deliberately no `plugin.json` or `package.json` here: omp reads `skills/` and `commands/` of an extension root itself.
